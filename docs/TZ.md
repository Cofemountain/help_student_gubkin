# ТЕХНИЧЕСКОЕ ЗАДАНИЕ (MVP)
## Образовательная платформа взаимопомощи по ФИЗИКЕ (7–9 классы) для мессенджера МАКС (MAX)

> **Статус документа:** Согласованная рабочая версия (MVP)  
> **Целевая платформа:** Российский мессенджер **МАКС (MAX)** (`dev.max.ru`, `platform-api2.max.ru`)  
> **Единственный предмет:** ФИЗИКА (7, 8, 9 классы)  
> **Команда:** 3 разработчика (Backend, MAX Bot, Frontend Mini App)  
> **Формат продукта:** Чат-бот в МАКС + встроенный Mini App (WebApp)

---

### 1. ЦЕЛЬ И ГРАНИЦЫ MVP

Создать понятный и быстрый сервис взаимопомощи по **физике** внутри мессенджера МАКС:
1. **Ученик** за 1 минуту оставляет заявку на разбор задачи с фото условия, выбором класса/темы и удобного времени.
2. **Помощник/Тьютор** видит задачу в ленте, откликается и получает прямую ссылку на личный чат с учеником в МАКС.
3. **Разбор и звонок:** В назначенное время стороны созваниваются через **нативные аудио/видеозвонки МАКС** прямо в личном диалоге.
4. **Завершение задачи:**
   - *Экспресс-сценарий:* Разбор завершен во время звонка $\rightarrow$ тьютор закрывает задачу, ученик подтверждает $\rightarrow$ начисление XP.
   - *Сценарий с ДЗ:* Тьютор прикрепляет задачу на закрепление $\rightarrow$ ученик присылает фото решения $\rightarrow$ тьютор принимает/отправляет на доработку.
5. **Геймификация:** Прозрачная система очков (XP) и 3 уровня мастерства по физике.

---

### 2. РОЛЕВАЯ МОДЕЛЬ

В MVP используется концепция **Peer-to-Peer с единым аккаунтом**:
- Любой зарегистрированный пользователь может как просить помощь, так и помогать другим (например, 9-классник может помочь 7-класснику).
- В интерфейсе Mini App реализован быстрый переключатель режимов:
  - **«Я учусь»** (список моих созданных заявок, статус текущих разборов, сдача ДЗ);
  - **«Я помогаю»** (общая доска открытых заявок по физике, мои текущие сессии, проверка ДЗ).

### 4. ПОЛЬЗОВАТЕЛЬСКИЙ СЦЕНАРИЙ (USER FLOW)

```
[Ученик] Создает заявку (фото + тема + время)
   │
   ▼
[Статус: OPEN] Заявка видна в ленте «Свободные задачи»
   │
   ▼
[Тьютор] Нажимает «Помочь»
   │
   ├──► [Статус: IN_PROGRESS]
   └──► Бот МАКС отправляет обоим взаимные ссылки на личный диалог: https://max.ru/{username}
   │
   ▼
[Созвон в МАКС] Стороны созваниваются через нативные аудио/видеозвонки МАКС
   │
   ├──────────────────────────────┬──────────────────────────────┐
   ▼                              ▼                              ▼
[Сценарий А: Экспресс]         [Сценарий Б: Выдача ДЗ]       [Отмена / Форс-мажор]
Тьютор: «Разбор завершен»       Тьютор прикрепляет ДЗ          Ученик отменяет заявку:
Ученик: «Подтвердить»           Ученик загружает фото решения  [Статус: CANCELLED]
   │                           [Статус: HW_SUBMITTED]         (только из статуса OPEN)
   │                           Тьютор: «Принять решение»
   │                              │
   └──────────────┬───────────────┘
                  ▼
          [Статус: COMPLETED]
      Начисление XP обоим участникам
```

#### Шаг 1. Создание заявки учеником
1. Ученик запускает бота МАКС и нажимает кнопку **«Открыть платформу»** (диплинк вида `https://max.ru/<botName>?startapp=...`).
2. В Mini App выбирает:
   - **Класс:** 7, 8 или 9;
   - **Тему по физике** из выпадающего списка;
   - Прикрепляет **1 фото условия задачи**;
   - Пишет комментарий (что именно вызвало затруднение);
   - Указывает удобное **время разбора** (например: *«Сегодня в 18:30»*).
3. Нажимает кнопку **«Оставить заявку»** (`POST /api/tasks`):
   - Заявка получает статус `OPEN`.
   - Бот МАКС делает уведомление в ленту/канал тьюторов: *«Новая задача по физике: {Класс} класс, тема: {Тема}»*.

#### Шаг 2. Взятие задачи тьютором и организация связи
1. Тьютор в режиме «Я помогаю» открывает вкладку «Свободные задачи».
2. Изучает условие задачи и указанное время, затем нажимает **«Помочь»** (`POST /api/tasks/{id}/accept`):
   - Статус меняется на `IN_PROGRESS`.
   - Бот МАКС присылает **ученику**:  
     *«Помощник {Имя} взял вашу задачу! Разбор назначен на {Время}. Напишите тьютору в МАКС: https://max.ru/{tutor_username}»*.
   - Бот МАКС присылает **тьютору**:  
     *«Вы взяли задачу ученика {Имя}. Напишите ученику в МАКС: https://max.ru/{student_username}»*.
3. **Механика звонка:** В назначенное время стороны переходят в личный диалог в мессенджере МАКС и созваниваются нажатием встроенной кнопки **📞 Аудиозвонок / Видеозвонок**.

#### Шаг 3. Завершение разбора (2 сценария на выбор)

* **Вариант А (Экспресс-разбор без ДЗ):**
  - Вопрос полностью разобран во время звонка.
  - Тьютор нажимает кнопку **«Завершить разбор»** $\rightarrow$ ученику в Mini App приходит запрос на подтверждение $\rightarrow$ ученик жмет **«Подтвердить»**.
  - Статус переходит в `COMPLETED`. Начисление: **+50 XP** ученику и **+50 XP** тьютору.

* **Вариант Б (С выдачей и проверкой ДЗ):**
  - Тьютор после звонка нажимает в карточке задачи **«Выдать ДЗ»**: вводит текст или фото аналогичной задачи (`POST /api/tasks/{id}/homework`).
  - Ученик решает задачу в тетради, загружает фото решения (`POST /api/tasks/{id}/submit-hw`).
  - Статус задачи меняется на `HW_SUBMITTED`.
  - Тьютор проверяет фото решения:
    - *«Принять»*: статус `COMPLETED`, начисление: **+100 XP** ученику, **+50 XP** тьютору.
    - *«На доработку»*: комментарий тьютора с указанием ошибки, ученик может прикрепить фото повторно.

#### Шаг 4. Отмена заявки (Edge Case)
- Пока задача в статусе `OPEN`, ученик может нажать кнопку **«Отменить заявку»** (`POST /api/tasks/{id}/cancel`) $\rightarrow$ статус `CANCELLED`.
- Если тьютор взял задачу, но не вышел на связь в течение 30 минут после назначенного времени, у ученика появляется кнопка **«Тьютор не ответил»** (возврат задачи в статус `OPEN`).

### 5. СТАТУСНАЯ МОДЕЛЬ ЗАДАЧ

| Статус в БД | Что видит Ученик | Что видит Тьютор | Доступные действия |
| :--- | :--- | :--- | :--- |
| `OPEN` | **«Поиск тьютора»** | **«Свободные задачи»** | Ученик: «Отменить». Тьютор: «Помочь». |
| `IN_PROGRESS` | **«В работе (звонок)»** | **«Мои сессии»** | Переход в чат МАКС. Тьютор: «Завершить» или «Выдать ДЗ». |
| `HW_SUBMITTED`| **«ДЗ на проверке»** | **«Проверить ДЗ»** | Тьютор: «Принять» или «На доработку». |
| `COMPLETED` | **«Завершено»** | **«В архиве»** | Просмотр истории и начисленных XP. |
| `CANCELLED` | **«Отменено»** | Скрыто из общей ленты | Просмотр в архиве. |

### 6. ГЕЙМИФИКАЦИЯ И УРОВНИ (ФИЗИКА)

#### Начисление очков (XP):
- **+20 XP** — Ученику за публикацию первой заявки;
- **+50 XP** — Тьютору и Ученику за проведенный экспресс-разбор;
- **+100 XP** — Ученику за успешно выполненное ДЗ;
- **+50 XP** — Тьютору за проверку ДЗ.

#### Ранги мастерства:
1. 🥉 `0 – 150 XP:` **«Юный наблюдатель»**
2. 🥈 `151 – 500 XP:` **«Знаток законов физики»**
3. 🥇 `500+ XP:` **«Мастер физики»**

### 7. АРХИТЕКТУРА И БАЗА ДАННЫХ

#### Авторизация в МАКС Mini App:
1. Mini App получает строку инициализации `initData` от платформы МАКС.
2. Фронтенд передает `initData` в заголовке `Authorization: Bearer <initData>` на бэкенд FastAPI.
3. Бэкенд валидирует цифровую подпись HMAC-SHA256 с использованием секретного ключа бота МАКС, извлекает `max_user_id`, имя и `username`, после чего генерирует сессионный токен.

#### Схема таблиц PostgreSQL:

1. **`users`**
   - `id`: SERIAL PRIMARY KEY
   - `max_user_id`: VARCHAR(64) UNIQUE NOT NULL (ID пользователя в МАКС)
   - `username`: VARCHAR(64) NULL (никнейм для ссылок https://max.ru/{username})
   - `full_name`: VARCHAR(128) NOT NULL
   - `xp`: INTEGER DEFAULT 0
   - `level`: INTEGER DEFAULT 1
   - `created_at`: TIMESTAMP DEFAULT NOW()

2. **`topics`**
   - `id`: SERIAL PRIMARY KEY
   - `grade`: INTEGER NOT NULL (7, 8 или 9)
   - `title`: VARCHAR(255) NOT NULL

3. **`tasks`**
   - `id`: SERIAL PRIMARY KEY
   - `student_id`: INTEGER REFERENCES `users(id)` NOT NULL
   - `tutor_id`: INTEGER REFERENCES `users(id)` NULL
   - `grade`: INTEGER NOT NULL
   - `topic_id`: INTEGER REFERENCES `topics(id)` NOT NULL
   - `description`: TEXT NOT NULL
   - `photo_url`: VARCHAR(512) NOT NULL
   - `scheduled_time`: VARCHAR(64) NOT NULL
   - `status`: VARCHAR(32) NOT NULL DEFAULT 'OPEN'
   - `hw_text`: TEXT NULL
   - `hw_photo_url`: VARCHAR(512) NULL
   - `hw_solution_url`: VARCHAR(512) NULL
   - `hw_comment`: TEXT NULL
   - `created_at`: TIMESTAMP DEFAULT NOW()
   - `updated_at`: TIMESTAMP DEFAULT NOW()

### 9. ПЛАН ТЕСТИРОВАНИЯ И ОТЛАДКИ (3 ЭТАПА)

1. **Этап 1 (Базовая связка):**
   - Запуск FastAPI + PostgreSQL + Бот МАКС на локальном/тестовом сервере.
   - Заполнение БД темами физики 7–9 классов.
   - Успешная авторизация в Mini App через тестовый `initData`.
2. **Этап 2 (Сквозной тест сценария «Созвон в МАКС»):**
   - Ученик создает задачу по теме «Архимедова сила» (7 класс) с фото.
   - Тьютор видит задачу в ленте и нажимает «Помочь».
   - Обоим приходят пуши в боте МАКС со ссылками на личный чат друг друга.
   - Проверяется экспресс-завершение разбора и начисление +50 XP.
3. **Этап 3 (Сквозной тест сценария с ДЗ):**
   - Тьютор выдает ДЗ через форму в Mini App.
   - Ученик получает пуш, прикрепляет фото решения.
   - Тьютор принимает решение $\rightarrow$ статус задачи переходит в `COMPLETED`, ученик получает +100 XP, тьютор +50 XP.
