# ТЕХНИЧЕСКОЕ ЗАДАНИЕ (MVP)
## Платформа взаимопомощи по ФИЗИКЕ: 9 КЛАСС — ПОДГОТОВКА К ОГЭ

> **Статус документа:** Базовая версия (MVP)  
> **Целевая аудитория:** Девятиклассники (подготовка к ОГЭ по физике) + Тьюторы / Студенты / Преподаватели  
> **Единственный фокус:** Физика 9 класс (структура и кодификатор ОГЭ)  
> **Команда:** 3 разработчика  
> **Формат продукта:** Чат-бот Telegram + мобильный WebApp (Telegram Mini App)

---

### 1. ЦЕЛЬ И ГРАНИЦЫ MVP

Создать специализированный сервис взаимопомощи для **сдачи ОГЭ по физике на максимум**:
1. **Быстрый запрос помощи:** Ученик за 1 минуту оставляет заявку на разбор непонятной задачи из ОГЭ с фото условия и указанием темы/номера блока.
2. **Доска задач для тьюторов:** Наставники видят открытые задачи по разделам ОГЭ, берут их в работу и назначают онлайн-сессию разбора.
3. **Закрепление через ДЗ:** После созвона/разбора тьютор прикрепляет аналогичную задачу формата ОГЭ, а ученик сдает фото развернутого решения.
4. **Геймификация «Путь к Отличнику ОГЭ»:** Прокачка от порога сдачи до максимума (XP, уровни, перекликающиеся с оценками ОГЭ 3 $\rightarrow$ 4 $\rightarrow$ 5).

---

### 2. КАТАЛОГ ТЕМ И БЛОКОВ ОГЭ (9 КЛАСС)

В MVP зашивается структурированный кодификатор ОГЭ по физике:

#### 1. Механические явления (ОГЭ)
1. Равноускоренное движение, ускорение, графики движения
2. Законы Ньютона, силы тяжести, упругости, трения
3. Закон сохранения импульса и энергии, работа и мощность
4. Статика: условия равновесия рычага, КПД простых механизмов
5. Давление в жидкостях и газах, сила Архимеда, плавание тел
6. Механические колебания и волны, звук

#### 2. Тепловые явления (ОГЭ)
7. Теплопередача, количество теплоты, удельная теплоемкость
8. Фазовые переходы: плавление, кипение, влажность воздуха
9. Уравнение теплового баланса и КПД тепловых двигателей

#### 3. Электромагнитные явления (ОГЭ)
10. Электрические цепи: последовательное и параллельное соединение, Закон Ома
11. Работа и мощность тока, Закон Джоуля-Ленца
12. Магнитное поле, электромагнитная индукция, опыты Фарадея
13. Геометрическая оптика: законы отражения и преломления, формулы и построения в линзах

#### 4. Квантовые явления (ОГЭ)
14. Строение атома и атомного ядра, изотопы
15. Радиоактивность: $\alpha$-, $\beta$-, $\gamma$-излучения, ядерные реакции

#### 5. Вторая часть ОГЭ (Повышенная сложность)
16. Качественные задачи с подробным объяснением (№20–22 ОГЭ)
17. Расчетные комбинированные задачи 2-й части (№23–25 ОГЭ)

### 3. ПОЛЬЗОВАТЕЛЬСКИЙ СЦЕНАРИЙ (FLOW)

#### Шаг 1. Создание заявки учеником 9 класса
1. Ученик открывает чат-бот и нажимает кнопку **«Открыть трекер ОГЭ»** (запуск WebApp).
2. В окне создания заявки выбирает:
   - **Раздел ОГЭ:** *Механика / Тепловые / Электромагнетизм / Кванты / Вторая часть (№20-25)*;
   - **Тему** из выпадающего списка выбранного раздела;
   - **Тип задачи:** *1-я часть (тестовая / базовая)* или *2-я часть (развернутый ответ)*;
   - Прикрепляет **фото условия задачи** (из сборника Камзеевой, РешуОГЭ, банка ФИПИ или пробника);
   - Текст вопроса: *«Не понимаю, как составить уравнение моментов»* или *«Путаюсь в знаках проекций»*;
   - Желаемое время созвона/разбора (например: *«Сегодня в 19:00»*).
3. Нажимает **«Опубликовать задачу»** (`POST /api/tasks`).
4. Тьюторы получают уведомление: *«Новая задача ОГЭ по теме: {Тема} (Часть {1/2})»*.

#### Шаг 2. Отклик тьютора
1. Тьютор на вкладке **«Свободные задачи»** фильтрует по разделу (например, «Вторая часть ОГЭ») и видит карточку с фото.
2. Нажимает кнопку **«Помочь разобрать»** (`POST /api/tasks/{id}/accept`).
3. Задача переходит в статус `IN_PROGRESS`.
4. Ученику в Telegram приходит пуш:  
   *«Тьютор @username взял вашу задачу ОГЭ! Разбор назначен на {Время}»* + контакт для связи.

#### Шаг 3. Разбор и контрольное ДЗ формата ОГЭ
1. Тьютор и ученик созваниваются, разбирают физический закон, оформление по критериям ФИПИ и решение.
2. Тьютор открывает карточку задачи в WebApp, нажимает **«Выдать ДЗ формата ОГЭ»**:
   - Прикрепляет фото или текст аналогичной прототипной задачи из ОГЭ;
   - Отправляет задание.
3. Ученик получает уведомление: *«Вам выдана задача ОГЭ для закрепления темы!»*.

#### Шаг 4. Сдача, проверка по критериям и начисление XP
1. Ученик оформляет решение в тетради (по правилам оформления 2-й части ОГЭ: «Дано», «СИ», формулы, пояснения) и загружает фото (`POST /api/homework/{id}/submit`).
2. Тьютор проверяет фото решения:
   - **Если верно:** нажимает **«Принять»** $\rightarrow$ Статус задачи `COMPLETED`, начисляются очки (+100 XP ученику, +50 XP тьютору), бот шлет поздравление.
   - **Если есть ошибки или неверное оформление:** нажимает **«На доработку»** с комментарием, за что на экзамене сняли бы баллы $\rightarrow$ ученик переделывает.

### 4. СТАТУСНАЯ МОДЕЛЬ ЗАДАЧ

| Статус в БД | Что видит Ученик | Что видит Тьютор |
| :--- | :--- | :--- |
| `OPEN` | **«Поиск тьютора ОГЭ»** | **«Свободные задачи ОГЭ»** (кнопка «Помочь разобрать») |
| `IN_PROGRESS` | **«Разбор назначен»** (контакт тьютора и время) | **«Мои разборы»** (кнопка «Выдать ДЗ») |
| `HW_SUBMITTED` | **«Решение на проверке»** | **«Проверка оформления ДЗ»** («Принять» / «На доработку») |
| `COMPLETED` | **«Усвоено (+100 XP)»** | **«В архиве (+50 XP)»** |

### 5. ГЕЙМИФИКАЦИЯ: ПУТЬ К ОТЛИЧНИКУ ОГЭ

Начисление опыта (XP) и 3 ранга, привязанные к шкале сдачи экзамена:

#### Начисление XP:
- **+50 XP** — за публикацию первой задачи по подготовке к ОГЭ;
- **+100 XP** — тьютору за проведенную консультацию;
- **+100 XP** — ученику за правильно решенную задачу ДЗ;
- **+50 XP** — тьютору за проверку решения и комментарии по критериям ФИПИ.

#### 3 уровня подготовки:
1. 🥉 `0 – 200 XP:` **«Порог сдачи (Оценка 3)»** — начальный уровень, разбор базовых понятий.
2. 🥈 `201 – 600 XP:` **«Уверенная 4-ка (Оценка 4)»** — освоены типовые расчетные задачи первой части.
3. 🥇 `600+ XP:` **«Отличник ОГЭ (Оценка 5)»** — мастер решения задач повышенной сложности второй части.

### 6. ЭКРАНЫ WEBAPP (MINI APP)

1. **Доска задач ОГЭ (Главная):**
   - Переключатель роли: `Я сдаю ОГЭ` / `Я тьютор`.
   - Фильтр по разделам ОГЭ (*Все / Механика / Теплота / Электричество / 2-я часть*).
   - Вкладки статусов: *Свободные / В работе / Проверка ДЗ / Архив*.
   - Кнопка `+ Разобрать задачу ОГЭ`.
2. **Экран публикации задачи:**
   - Выбор раздела ОГЭ и темы из справочника;
   - Переключатель части: `Часть 1 (тест)` / `Часть 2 (развернутый ответ)`;
   - Загрузка 1 фото условия;
   - Поле: «Что вызвало сложность?»;
   - Дата и время онлайн-разбора.
3. **Карточка задачи и сдачи ДЗ:**
   - Фото условия, раздел, статус, контакт наставника;
   - Блок проверки оформления ДЗ с кнопками «Принять» / «На доработку» и полем комментария.
4. **Профиль подготовки:**
   - Имя, Telegram username, текущий ранг (3/4/5), прогресс-бар XP до следующего балла ОГЭ.

### 7. РАСПРЕДЕЛЕНИЕ ЗАДАЧ МЕЖДУ 3 РАЗРАБОТЧИКАМИ

#### Разработчик 1 — Backend & Data (FastAPI + PostgreSQL + Alembic)
- Спроектировать таблицы: пользователи, справочник кодификатора ОГЭ, задачи ОГЭ, ДЗ, транзакции XP.
- Написать сид со всеми темами и блоками ОГЭ за 9 класс.
- Эндпоинты CRUD с фильтрами по разделам ОГЭ и статусам.
- Бизнес-логика защиты от накрутки XP и смены рангов (3 $\rightarrow$ 4 $\rightarrow$ 5).

#### Разработчик 2 — Bot & Storage & Push (Aiogram 3 / Python)
- Меню запуска WebApp c передачей данных пользователя.
- Загрузка и выдача фото условий и решений задач.
- Уведомления о статусе подготовки: взятие задачи, приглашение на разбор, напоминание о ДЗ, начисление XP.

#### Разработчик 3 — Frontend (Mini App / Vite + Tailwind или Vanilla)
- Интерфейс доски с фильтрацией по блокам ОГЭ.
- Форма создания задачи под стандарты ОГЭ.
- Профиль с бейджами оценок (3, 4, 5) и шкалой баллов.
- Интеграция с API бэкенда.
